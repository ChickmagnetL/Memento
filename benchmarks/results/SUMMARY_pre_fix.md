## 备注 / 已知问题

- 10/10 视频均已索引入 KB；其中 3 篇 clean 失败后按 raw 索引、无 L2/L3：增肌饮食、GDP、系统设计 2h → L2/L3 覆盖 70%。
- B 站 5 条视频无软字幕，走 ASR fallback 灌库。
- 检索混合整体提升有限（R@5 约 +1% 相对 / +1pp 绝对），因纯向量已近天花板（R@5≈94%）；jargon/专有名词切片上混合相对纯向量约 +3pp（R@5 95.45% vs 92.42%），故事更清晰。
- 混合检索延迟约 7× 纯向量：HybridRetriever 每次 query 经 `scroll_all_points()` 重建 BM25 语料，属已知实现瓶颈。
- 端到端 chat 延迟（首 token / 完整回复）本轮跳过，仅测检索层。
- 路由总准确率 79.17%：search 类常见「常识题」未调工具被记为 memory；memory 类样本仅 n=4，波动大；summary 路由相对稳健（9/10）。
- 架构：Layered 相对 Flat 均分 +0.20，胜率 30%（平局 40%）；模糊「这个视频讲什么」类题在无 L3 brief 时易错绑文档，Layered 在缺 L2/L3 的文档上可出现低分（1 分）outlier。
- 向量维度实测为 **1024**（Qwen3-Embedding-0.6B smoke），非 768。
